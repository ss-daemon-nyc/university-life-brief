# University Life — Strategy & Organizational Development

An award-style landing page for the NYU Division of University Life Monthly Brief
(June 2026), built with **GSAP** and **Three.js**.

## Highlights
- Hero with a custom GLSL-distorted icosahedron, wireframe shell, and particle field
- GSAP ScrollTrigger reveals, animated stat counters, and a second Three.js particle scene
- Fully responsive, mobile-friendly, single-file (`index.html`) — no build step

## Deploy
This is a static site. Any host works; for GitHub Pages, enable Pages on the
`main` branch (root). All dependencies load from HTTPS CDNs.
